# 🚀 Dashboard Custom (ASP.NET Core & Angular)

Tableau de bord personnel et modulaire développé avec **ASP.NET Core (.NET 10)** pour le backend et **Angular** pour le front-end. Ce projet permet notamment de gérer et lancer des applications locales de manière sécurisée et dynamique, de suivre les performances du PC, de contrôler le son et gérer une lampe Xiaomi.

---

## 🛠️ Stack Technique

- **Backend :** C#, ASP.NET Core, .NET 10 (Architecture API REST, services Windows, gestion dynamique de la configuration).
- **Frontend :** Angular, TypeScript, Tailwind CSS.
- **Stockage :** JSON.

---

## 📂 Structure du Projet

- `DashboardCustom.Server/` : API Backend ASP.NET Core & Services
- `DashboardCustom.Client/` : Application Front-end Angular
- `DashboardCustom.sln` : Fichier solution Visual Studio
